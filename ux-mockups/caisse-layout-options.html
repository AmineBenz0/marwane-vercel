Options pour la Caisse

La page Caisse doit rester centrée sur ce qu’elle seule doit expliquer: l’argent disponible maintenant, sa composition cash + LC, et les mouvements de caisse.

Direction retenue: Option 3 + registre simple
Ce qu’on évite de dupliquer Pas de détail produit/bâtiment, pas de tableau complet client/fournisseur, pas de liste complète des LC, pas de soldes bancaires. Ces informations existent déjà dans leurs sections dédiées.
Caisse = argent disponible + mouvements
