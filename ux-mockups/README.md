# UX mockups for simpler daily usage

These files are static HTML prototypes. They do not change the React app.

- `index.html`: quick overview and links to every option.
- `option-a-daily-command-center.html`: simplest daily landing page with high-priority actions and alerts.
- `option-b-simple-registers.html`: cleaner list/register pattern for transactions, caisse, clients, fournisseurs, charges, and LC.
- `option-c-guided-entry.html`: guided form pattern for creating transactions, production entries, payments, and expenses.

Recommended direction: combine option A for the home/dashboard, option B for list pages, and option C for creation/editing flows.
