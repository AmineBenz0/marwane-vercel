Production + stock

Make the daily farm work feel obvious.

The user should not need to understand databases, transaction models, or inventory theory. The screen should answer three plain questions: what did each building produce today, what left the stock, and what is still available to sell.

What the handwritten note asks for Daily production by building, then stock per building based on production, sold eggs, and lost eggs.
UX problem to solve The current production form records eggs, but the stock story is not visible enough for a non-technical operator.
Design rule Show the formula in words and numbers: Produced today - Sold - Lost = Available stock.
1

Recommendation: building stock board + quick daily entry

This is the best fit for a non-technical farm user. It starts with buildings, not tables. Each card shows stock, the exact calculation, and the next action.
